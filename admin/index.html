Organiser Upload Guidelines & Instructions

  • Upload photos to your Drive folder, then refresh the preview below.
  • Formats: Use JPG, PNG, or WebP. (iPhone users: set Camera to Most Compatible, as Apple HEIC files cannot be rendered by web browsers).
  • File Size: Recommended under 2 MB per image for instant mobile loading over cellular data.
  • Titles: The file name in Google Drive automatically becomes the display title on the website (e.g. Maha Pratyangira Homam.jpg → Maha Pratyangira Homam).
  • Captions: Enter spiritual descriptions in the file's Description field in Google Drive.
  • Overrides & Hiding: Use the live preview below to temporarily hide any photo or override titles/captions without deleting the file from Drive.
